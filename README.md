# D&D Character Sheets

A simple D&D 5e character sheet app for Android phone and tablet. It is a **Progressive Web App (PWA)**: plain HTML/JS, no build step, no account. Open it in Chrome, choose **Add to Home screen / Install app**, and it runs full-screen and works offline like a normal app.

## Features
- Multiple characters, saved on the device (browser localStorage)
- Info: name, class, subclass, level, race, background, alignment, XP, AC, speed, proficiency bonus, initiative, passive Perception
- Stats: ability scores with modifiers, saving throws and skills (proficient / expertise); tap any modifier to roll it
- HP: damage / heal / temp HP, hit dice, death saves, short and long rest
- Rolls: dice buttons, free-form expressions (`2d6+3`, `4d6kh3`), advantage / disadvantage, attacks with to-hit and damage, roll history
- Items: inventory with quantity, weight, notes, equipped; coins; total weight vs carry capacity
- Spells: spell save DC and attack, spell slots filled in automatically from class and level (tap to use / restore, or set them manually for multiclass/homebrew), the full SRD spell list to search and add (filtered by class), prepared toggle, cast at a chosen slot level, custom spells
- Story: backstory, personality, notes
- Export / import JSON backups (also how to copy characters between phone and tablet)

## Running it
Any static web host works. The easiest is **GitHub Pages**: repo Settings → Pages → deploy from branch `main`, folder `/`. Then open the Pages URL on each device in Chrome and install it.

Locally: `python3 -m http.server` in this folder and open http://localhost:8000.

> Characters live only on the device where you created them. Use **Export all** regularly as a backup, and **Import file** to move them to another device.

When you change app files, bump `VERSION` in `sw.js` so installed copies pick up the update.

## Rules data
`data/srd.js` is generated by `tools/build-srd.py` from the [5e-bits SRD database](https://github.com/5e-bits/5e-database) (`src/2014/en`). It contains the D&D 5e System Reference Document 5.1 content by Wizards of the Coast, licensed under CC-BY-4.0. Only SRD subclasses and spells are bundled; anything else can be typed in or added as a custom spell.
